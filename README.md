#music Game.html

Web Audio APIによる自動BPM解析と、描画最適化（GPUアクセラレーション）を実装したブラウザ向け4レーンリズムゲーム

## 1. プロジェクト概要
ユーザーが読み込んだ任意の楽曲（MP3/WAV等）からBPMを自動解析し、動的に4レーンのノーツ譜面を生成してプレイできるブラウザ完結型のリズムゲームです。  
「楽曲のビートと指先が一致する爽快感」を体験として届けるため、低遅延なキーレスポンスと滑らかな描画パフォーマンスを追求しました。

### 主な特徴
- **楽曲アップロード＆自動譜面生成**: 任意の音声ファイルを読み込むだけで、楽曲のテンポに合わせた譜面を即座に動的生成。
- **フレームレート非依存の移動制御**: 可変FPS環境でもノーツの落下速度が狂わないよう、$\Delta t$（前フレームからの経過時間）に基づく座標計算を採用。
- **視認性と手触り（UX）の設計**: ノーツ認識から打鍵までの先読み時間を1.5秒に設定し、直感的なキー押下フィードバック（ハイライト・判定表示）を実装。

## 2. こだわった技術的工夫・最適化

### ① Web Audio APIを用いた自己相関法によるBPM解析
- `AudioContext` でデコードした波形データに対し、ハニング窓関数を適用してスペクトル漏れを抑制。
- 自己相関（Autocorrelation）を算出して支配的な周期ラグを特定し、楽曲のBPMをブラウザ上で高速に自動推定。

### ② CSS Transformによる描画負荷軽減（リフロー防止）
- ノーツの移動に `top` 座標ではなく `transform: translateY()` を採用。
- `will-change: transform, opacity;` を指定し、ブラウザの再レイアウト（リフロー）を回避してGPUアクセラレーションを活用することで、ノーツ集中時のカクつきを防止。

### ③ ミリ秒・ピクセル単位の多段階判定ロジック
- 判定ラインとの絶対距離差（$\vert{}y - \text{hitY}\vert{}$）に基づき、PERFECT（<10px）、GREAT（<25px）、GOOD（<40px）、MISSを判定。
- 判定文字の切り替え時に `opacity` を制御し、DOM再描画によるレイアウト崩れやチラつきを排除。
